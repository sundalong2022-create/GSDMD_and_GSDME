# T3 — ICI systematic meta-analysis

## Sessions

Run one session per script:

1. src/t3_ici/01_harmonize.py
2. src/t3_ici/02_meta.py
3. src/t3_ici/03_stratify.py

## Inputs and effect definitions

The public minimum set is GSE78220, GSE91061, GSE126044, GSE176307, GSE135222, and IMvigor210. TIGER/PRJNA482620 and PRJEB25780 are optional and must not block the analysis. Harmonize CR/PR to R and SD/PD to NR; keep OS as a separate endpoint.

Freeze the effect scale before harmonization: response uses log odds ratio per one predeclared score unit and OS uses log hazard ratio per one predeclared score unit, with standard errors and event definitions recorded. Cohort-level effects go to cohort_effects.tsv; the source and method for each cohort-specific compartment proxy go to cohort_strata.tsv; pooled results go to meta.tsv; stratified pooled results go to meta_stratified.tsv. Preserve the effect scale in every table; never pool response and OS effects together.

## Stratification constraint

Do not assign an independent ICI cohort to endothelial-high or epithelial-high using TCGA proportions. Estimate the compartment proxy in the ICI cohort itself or use a proxy frozen in the config, and record its source.

## G3 acceptance

At least six public/usable cohorts must contribute to the primary endpoint. Do not average subgroup-specific I² values. Fit the same random-effects meta-regression before and after adding the predeclared compartment stratum, and compare residual I² from those models; G3 passes when 1 − residual I²(with stratum)/I²(intercept-only) is at least 20%. Report cohort counts per stratum and retain leave-one-out results. If a stratum has too few cohorts to estimate heterogeneity, G3 is not evaluable rather than passed.
