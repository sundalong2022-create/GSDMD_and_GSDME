# T5 — resource and manuscript package

## Sessions

Run one session per script or app component:

1. src/t5_resource/app.py
2. src/t5_resource/export_zenodo.py
3. manuscript number/figure automation

## Inputs and outputs

Read only validated result tables and figures from the selected run directory. The app exposes S1, forest plots, and spatial plots without recomputing statistics. The export session writes a versioned Zenodo bundle manifest and checksums; it does not publish or upload without explicit user action.

Manuscript templates pull all figure identifiers and numeric claims from result files. Any missing result or schema failure stops the export and reports the source path.

## Acceptance

The app starts from a clean environment, the export manifest is reproducible, all referenced figures exist in PDF and PNG where required, and make verify passes.
