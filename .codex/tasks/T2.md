# T2 — spatial validation

## Sessions

Run one session per script:

1. src/t2_spatial/01_qc_cluster.py
2. src/t2_spatial/02_deconv_RCTD.R
3. src/t2_spatial/03_spatial_stats.py
4. src/t2_spatial/04_immune_distance.py

## Inputs and cohort selection

Visium samples must already be present under data/raw/visium/<cancer>/, with filtered_feature_bc_matrix.h5 and spatial/. Primary cancers are ESCA, BRCA, NSCLC, CRC, and KIRC; HNSCC remains a reserve cancer because earlier manifests used it. The final sample list and release/source identifiers must be frozen before QC.

The RCTD reference is the corresponding TISCH2 single-cell reference and must be supplied as an input artifact. The RCTD session may not silently use a reference from another cancer.

## Methods and outputs

QC thresholds live in config/params.yaml. RCTD produces per-spot cell proportions. Spatial statistics define GSDMD-high regions by the configured quantile and use sample-level permutation nulls. Moran's I and neighborhood enrichment go to spot_stats.tsv; nearest-neighbor distance tests go to distance_stats.tsv.

Permutation tests preserve the within-slice spatial structure and are run separately per sample/slice; record the permutation count and spot count in the output. Spots estimate a sample-level spatial statistic and are never counted as independent biological replicates. Define the endothelial region as a predeclared endothelial-proportion threshold combined with GSDMD-high status. If a cancer has only one usable slice, report its within-slice result as descriptive and do not treat it as cancer-level replication.

## G2 acceptance and downgrade

G2 requires at least 3 of 5 primary cancers to show both endothelial enrichment in GSDMD-high regions and a larger CD8 distance with permutation p < 0.05. The denominator is the number of primary cancers with QC-passing samples, a valid RCTD fit, and enough independent slices to estimate a cancer-level result; record that minimum in config before analysis. If fewer than two cancers pass, use the exploratory spatial title and move T2 to supplementary status; do not call the endothelial line a co-primary result.
