# T0 — freeze existing single-cell results

## Sessions

Run one session for each script, in order:

1. src/t0_freeze/01_make_table_s1.py
2. src/t0_freeze/02_plot_fig1_3.py

## Inputs

The following files must already exist under data/raw/t0/ (or their exact paths must be recorded in the session log):

- tisch2-gsdm-mixed-model-bh.csv
- sensitivity-report.md
- celltype-stats.csv

Do not recreate, impute, or download them in the T0 sessions.

## Outputs

The first script writes table_s1.tsv and table_s2.tsv under --outdir, using the registered T0 schema. proxy_note is required for every row and uses a fixed vocabulary documented in the script. The second script writes Figure 1–3 as both PDF and PNG under the package output/figure directory.

## Acceptance

- S1 row count equals the number of valid input tests after exclusions; report the expected 16 × 2 × 3 = 96 only when all 96 tests are present.
- The annotation column has no empty values and explicitly records HNSC GSDME LOO sign reversal, two q/robust inconsistencies, LIHC/NSCLC127465 low endothelial percentage, and malignant proxy status.
- Both PDF and PNG exist for Figures 1–3.
- Run the T0-specific tests and make verify.

## Blockers and limits

T0 is blocked while the three input files are absent. Do not open a T0 implementation session until they are copied into data/raw/.
