# T4 — death-program specificity

## Sessions

Run one session per script:

1. src/t4_death/01_death_scores.py
2. src/t4_death/02_partial_corr.py

## Inputs and methods

KEGG hsa04210, hsa04217, and hsa04216 GMT files and the FerrDb version must already be present under data/raw/genesets/. The score session uses the frozen ssGSEA implementation and writes the three death-program scores plus the GSDM scores.

The partial-correlation session controls tumor purity and the other three death-program scores. Use partial_corr.tsv for score-to-death-program associations and immune_assoc.tsv for the required GSDM-to-immune associations; the latter includes immune_cell.

## Acceptance

Report the fraction of GSDM–immune associations that remain significant after controlling for all three death programs, with its numerator, denominator, and significance threshold. Run task tests and make verify.
